## 📂 Featured Project

### 📦 Inventory Management System

A console-based Inventory Management System built using **C++** and **Object-Oriented Programming** concepts.

#### Features

✅ Add Products

✅ Search Products

✅ Update Product Details

✅ Delete Products

✅ Display Inventory Records

✅ Category Management

#### Concepts Implemented

- Classes & Objects
- Inheritance
- Runtime Polymorphism
- Encapsulation
- File Handling
- Pointers
- Menu-Driven Architecture

#### Objective

The system simplifies inventory tracking and management while demonstrating practical implementation of OOP principles in C++.
